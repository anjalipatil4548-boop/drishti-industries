# Drishti Industries — Autonomous Drone & Surveillance Systems

> **Live Website:** [https://drishti-industries.pages.dev/](https://drishti-industries.pages.dev/)

**Drishti Industries** (Bengaluru, India) builds autonomous aerial floats and unmanned surveillance drones engineered to survey, inspect, and monitor land, critical assets, agriculture, and perimeter security—with no pilot in the loop.

## Key Features
- **Autonomous Drone Fleet Architecture:** Four specialized autonomous float platforms built for continuous aerial observation, precision mapping, and remote inspection.
- **Interactive 3D Visuals & Grid Telemetry UI:** Sleek dark-mode engineering interface with crisp typography (`General Sans`) and responsive layout grid.
- **Mission Profiles & Field Notes:** Dedicated sections covering agriculture monitoring, industrial asset inspection, security patrol, and exploration workflows.
- **Interactive Contact Inquiry Endpoint:** Built-in contact form support for local demo & static edge deployments.

## Tech Stack
- Astro Static Framework & Modular CSS Architecture
- Interactive 3D Canvas & Vector Telemetry Assets
- Deployed globally on **Cloudflare Pages**
